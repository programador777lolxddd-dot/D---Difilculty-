# D — Difficulty

Una librería de Python intencionalmente difícil de usar. Sin piedad. 🧩

**D-Difficulty** es un pequeño proyecto de experimentación y humor para jugar con una API misteriosa: atributos dinámicos, niveles de dificultad, operaciones aritméticas y secretos por desbloquear.

## Instalación

```bash
python -m pip install D-Difficulty
```

## Ejemplo

```python
import D

print(D.hello())
print(D.add(2, 3))
print(D.state())
```

La API cambia según el nivel de dificultad:

```python
import D

D.level(2)
print(D.add(a=2, b=3))
```

Explora el código fuente para descubrir el resto. La dificultad es parte del chiste. 😉

## Requisitos

- Python 3.7 o superior.
